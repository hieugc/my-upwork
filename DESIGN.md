# my-upwork — Design Context

## Global quality floor
- WCAG 2.2 AA target
- visible focus states
- reduced-motion support
- no hidden scrollbars
- stable loading geometry
- minimum 44px touch targets for primary mobile controls
- semantic HTML and accessible labels

## Shared system
Shared primitives may cover accessibility mechanics, layout utilities, buttons, dialogs and form states, but must expose product-specific variants.

## Product identities
### ChainPulse
Institutional Web3 growth agency. Paper #F5F7FB, ink #0B1020, lime #D9FF66, violet #6D5DFC. Signature: campaign-velocity analytics object.

### OrbitOps
Automation control-room aesthetic. Light steel surfaces, electric blue, diagrammatic connectors. Signature: animated workflow graph.

### MetricFlow
Calm product-led SaaS. Dense but airy metrics, cobalt/teal accents. Signature: live metric lens that changes dashboard context.

### Maison Estate
Editorial luxury property. Warm limestone, charcoal, bronze accents, large photography windows. Signature: cinematic property rail.

### NOMA Coffee
Warm contemporary retail. Oat, espresso, cherry-red micro-accent. Signature: menu ticket / order tray interaction.

### AURA Commerce
Fashion editorial commerce. High-white space, ink, seasonal color. Signature: split product storytelling + sticky cart drawer.

### Northstar Studio
Creative dev studio. Modular grid, typographic motion, saturated coral detail. Signature: project canvas that rearranges by discipline.

### LedgerX UI
Financial terminal refined for modern web. Dark slate, cool cyan, positive/negative semantic colors. Signature: portfolio pulse chart and contextual trade panel.

## Design ownership
Each app owns its product tokens. Shared packages must not override product identity.
